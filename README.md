# debugmcp.io

Source for the mcp-debugger project website, served by GitHub Pages at https://debugmcp.io.

- Single static page, no build step, no external resources (fonts, scripts, and styles are all inline/system).
- Deploy: push to `main`; Pages publishes from the repo root.
- Custom domain is set via the `CNAME` file; DNS lives at the registrar (see debugmcp/ops runbooks).
